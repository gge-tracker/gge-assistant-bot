# Security Policy

## Supported Versions

Since this bot is designed to be run from the latest available code on the `main` or `dev` branch, only the latest version is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability within this project, please report it privately so it can be patched before being publicly disclosed. 

You can report a vulnerability by:
1. Sending a private message on Discord to the developer (`hydrocat.d`).
2. Using the **"Report a vulnerability"** button in the Security tab of this repository (if enabled).

All security vulnerability reports will be addressed as quickly as possible.
